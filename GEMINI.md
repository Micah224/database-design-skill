# Gemini CLI

This repository ships an Agent Skill at `skills/database-design-discovery/SKILL.md`. Read that file and follow its workflow whenever the task involves designing or reviewing a database schema, choosing a database engine, or modelling users, roles, permissions, tenants, staff, departments, branches, admins, audit or consent.

`AGENTS.md` has the trigger conditions and the script commands; the scripts are plain Node.js and need no installation.
